#Module 2 Creative Task
===========

This folder holds records and code for Module 2. 

In particular, creativetask.py holds the code for the group project conducted by Coby, Gabriel, and Jam - Keep Talking and Nobody Explodes: Raspberry Pi Edition. 

To implement this code and replicate the game, use the following hardware components:

Count	Name
1	Raspberry Pi
1	ESP32 Microcontroller
4	Buttons
3	Joysticks
2	Switches
1	Breadboard
Dozens	Wires
1	3-D Printed Enclosure
1	Cardboard Base
1	Game Manual
2	OLED Displays

Additionally, the game manual can be found at Keep Talking and Nobody Explodes.pdf, and can be assembled with printing/cutout/stapling.
