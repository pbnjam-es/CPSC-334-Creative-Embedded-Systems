#Module 3 Creative Task
===========

This folder holds records and code for Module 3. 

Final code for this project can be found in compostNode, compost.scd, and pedal_listener.py. Other folders, such as macAddress, sensorTest, pedalUDP, and touchTest are
Arduino scripts used in the process of testing. This project involved code written in Arduino scripts, Python, and SuperCollider. 

Running this project requires the ESP32 and the Pi to be on the same internet connection, with the Pi requiring the pw-jack and sclang
libraries.
