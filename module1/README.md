Module 1 Creative Task
===========

This code is used to implement and replicate the module 1 task and sketch, created in Processing. 

sketch/sketch.pde contains the Processing code for the sketch itself, while run.sh is able to run and draw the sketch
through Bash. This enables the Raspberry Pi's labwc autostart file to include a line that runs the file run.sh on startup
(not included in this repo), allowing the sketch to be drawn and simulated when the Raspberry Pi boots.
